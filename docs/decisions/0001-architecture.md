# ADR-0001：第一阶段采用单体 Web、独立 worker 与 PostgreSQL 工作流

- 状态：已采用
- 日期：2026-09-15

## 决策

使用 Next.js 提供中文管理界面和业务 API，独立 Node worker 处理持久任务，PostgreSQL 同时保存业务实体、审批记录、执行尝试和人工任务。Prisma 负责 schema、类型和迁移。

## 原因

这一结构能在不引入微服务或第二套队列的情况下，把权限、审批、幂等和恢复规则放进确定性程序。模型只通过结构化适配器生成草稿或解释数据，不掌握发布凭据和绕过审批的路径。

## 后果

- Web 进程退出不会丢失队列状态，worker 可恢复未完成任务。
- 第一阶段需要 PostgreSQL；不提供 SQLite 分支，以免产生不同的并发语义。
- Activepieces 可在后续承担外部触发，Postiz/WordPress 可作为适配器，但都不能成为核心状态权威。
