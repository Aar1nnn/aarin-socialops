## 目标与边界

在不削弱第一阶段审批、版本、幂等、客户隔离和人工交接规则的前提下，为一个专用测试 Facebook Page 建立真实连接、发布、查询、指标和公开评论导入闭环。真实凭据只从服务器环境变量解析，数据库仅保存 `credentialRef` 和非敏感状态。

本阶段不实现 Facebook 群组自动化、自动回复、自动私信、自动报价或广告投放。吕总客户不得用模拟发布结果代替真实结果。

## 不变量

- 发布前必须再次验证：客户范围、最新内容版本、最新批准、产品资料版本和账号连接状态。
- `DEMO` 只能使用模拟适配器；`LIVE` 只能使用已验证的真实适配器；`DRAFT` 不得发布。
- 外部请求发出后超时且无法确认结果时写入 `UNKNOWN`，不进入自动重试队列。
- Graph API 不支持本项目业务幂等键；本地唯一任务阻止重复发送，远端 ID 用于后续查询。没有远端 ID 的未知结果必须人工对账。
- 评论和其他外部文本始终作为不可信数据，不得改变审批或执行规则。
